# AGENTS.md

This folder contains the BridgeFlow Vite/React webapp. Protocol documents live in `../protocols/` and are bundled by `src/lib/workspace.ts`.

- Make UI, rendering, parsing, and build changes here.
- Keep protocol graph content in `../protocols/`; do not create a second copy in this folder.
- Run `pnpm dev` for local development and `pnpm build` to verify production bundling.
